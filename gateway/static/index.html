About

        
ZCode Universal Model Gateway (ZUMG)

        

          
ZUMG lets ZCode connect to a single local OpenAI Responses-compatible endpoint while the gateway forwards requests to multiple providers and models. Reasoning tiers are fully configurable and are exposed as virtual model IDs such as model-name@tier.
